# Task 7 · Write it up

**Goal:** turn the analysis into prose — the everyday research task of drafting a paragraph
from your results.

## Paste this into Claude Code

> Using the results from the tasks so far, draft a ~150-word "Results" paragraph for a report.
> State the sample size, the per-species body-mass comparison with numbers, the flipper–mass
> relationship (overall vs within species), and the missing data. Keep it factual — no
> speculation beyond what the data shows.

## What to expect / check
- A tight paragraph citing the real figures: **344 penguins**, Gentoo heaviest (**~5076 g**)
  vs Adelie (**~3701 g**), flipper–mass correlation **~0.87 overall but ~0.5–0.7 within
  species**, and the **11 rows with missing values**.
- **Read it critically.** Every number should trace back to a task you already ran. This is a
  first draft you edit and own — not a final artifact to paste unread. If a figure looks off,
  ask it where the number came from.

## Make it yours
- Ask for the same content as **three bullet points for a slide**, or in the style of your
  field's journal. Reusing your analysis in different forms is where an agent saves real time.
